# Rivet – Mobile Landing

Mobile-only, step-based landing page for Rivet (React + Framer Motion + SCSS modules).

**Live:** [rivet-flame.vercel.app](https://rivet-flame.vercel.app/) (best viewed on a phone)

## Run locally

```bash
npm install
npm start        # http://localhost:3000
npm run build    # production build in /build
```

Tip: `?step=N` opens a specific screen directly (e.g. `http://localhost:3000/?step=4`).
